**Goal:** Players join with unique names, get a unique color and a team seat, see two panels with Ready / In match / Post-match badges, can switch teams, and the host can toggle FFA/Team, kick Ready/Post-match players, and be told why Start is illegal. Host token transfers on leave. Start itself is **not** implemented here — only the **pure start-rule function** and a host button that shows the error or sends `start_match` (P3 handles the message). If P3 is not done, `start_match` is ignored by the room (or replies `start_error` with `"not implemented"` only if you have not yet merged P3 — prefer: implement `canStart` now and wire `start_match` as a no-op that still runs `canStart` and broadcasts `start_error` on failure; on success send `start_ok` and leave phase as lobby until P3).

**Architecture:** Pure lobby functions in `shared` (testable). `ArenaRoom` calls them. Join uses Colyseus `options: { name }`. Client JoinScene collects the name. LobbyScene is Phaser.

**Depends on:** P1 Done. **Blocks:** P3. **May run parallel with:** P4.

### Task 1: Name validation (TDD)

- [ ] **Step 1: Write `names.test.ts`**

```ts
import { describe, expect, it } from "vitest";
import { normalizeName, validateName, isNameTaken } from "./names.js";

describe("normalizeName", () => {
  it("trims whitespace", () => {
    expect(normalizeName("  Ada  ")).toBe("Ada");
  });
});

describe("validateName", () => {
  it("rejects empty after trim", () => {
    expect(validateName("   ")).toEqual({ ok: false, error: "Name must be 1–16 characters" });
  });
  it("rejects longer than 16", () => {
    expect(validateName("a".repeat(17)).ok).toBe(false);
  });
  it("accepts 1–16", () => {
    expect(validateName("A")).toEqual({ ok: true, name: "A" });
    expect(validateName("abcdefghijklmnop")).toEqual({ ok: true, name: "abcdefghijklmnop" });
  });
});

describe("isNameTaken", () => {
  const existing = ["Ada", "bob"];
  it("is case-insensitive", () => {
    expect(isNameTaken(existing, "ada")).toBe(true);
    expect(isNameTaken(existing, "BOB")).toBe(true);
    expect(isNameTaken(existing, "Cam")).toBe(false);
  });
});
```

- [ ] **Step 2: `start-rules.test.ts`**

```ts
import { describe, expect, it } from "vitest";
import { canStart } from "./start-rules.js";
import { GameMode } from "../constants.js";

const ready = (team: 0 | 1) => ({ status: "ready" as const, team });

describe("canStart FFA", () => {
  it("rejects fewer than 2 ready", () => {
    expect(canStart(GameMode.FFA, [ready(0)]).ok).toBe(false);
  });
  it("accepts 2+ ready regardless of team", () => {
    expect(canStart(GameMode.FFA, [ready(0), ready(1)]).ok).toBe(true);
  });
  it("ignores in-match and post-match", () => {
    const players = [
      ready(0),
      { status: "in_match" as const, team: 0 },
      { status: "post_match" as const, team: 1 },
    ];
    expect(canStart(GameMode.FFA, players).ok).toBe(false);
  });
});

describe("canStart TEAM", () => {
  it("accepts 1v1 / 2v2 / 3v3 ready", () => {
    expect(canStart(GameMode.TEAM, [ready(0), ready(1)]).ok).toBe(true);
    expect(canStart(GameMode.TEAM, [ready(0), ready(0), ready(1), ready(1)]).ok).toBe(true);
  });
  it("rejects unequal ready teams", () => {
    expect(canStart(GameMode.TEAM, [ready(0), ready(0), ready(1)]).ok).toBe(false);
  });
});
```

`canStart` returns `{ ok: true } | { ok: false; error: string }`. Error strings (stable, shown in UI):

- FFA < 2: `"Need at least 2 ready players"`
- Team unequal: `"Teams must be equal to start"`
- Team 0 ready: `"Need at least 1 ready player per team"`

### Task 3: Server room — join options, messages, host transfer

Modify `ArenaRoom`:

**`onJoin(client, options)`**
1. `validateName(options?.name)`. If fail, `client.leave(4000, error)` (or `throw new ServerError(4000, error)` — Colyseus 0.15 `ServerError`).
2. `isNameTaken` against current `state.players` names → `ServerError(4001, "Name is taken")`.
3. `pickColor` / `pickTeam` from current players.
4. Set `name`, `colorId`, `team`, `joinedAtTick = state.tick`, `status = READY`.
5. First joiner is host (keep P0 behavior).

Room full: Colyseus already rejects at `maxClients`. Client should show "Room is full".

**`onLeave`**
1. Delete player.
2. If host left and players remain: new host = smallest `joinedAtTick`, tiebreak smallest `sessionId`.

**Messages**
- `switch_team`: only if `player.status === READY`. Flip `team` 0↔1.
- `set_mode`: only if sender is host **and** no player has `status === IN_MATCH`. Set `state.mode`.
- `kick`: only if sender is host. Target must exist and be READY or POST_MATCH. `client.leave(4002, "Kicked")`.
- `start_match`: only host. Run `canStart` on current players (map `PlayerStatus` → `"ready" | "in_match" | "post_match"`). On failure, `client.send(MSG_START_ERROR, { error })`. On success in P2: do nothing else (P3 will start the flow). Add a comment `// P3: begin car select`.

Replace P0’s auto-join-without-name. `onJoin` without a valid name is an error — the client must send `{ name }`.
