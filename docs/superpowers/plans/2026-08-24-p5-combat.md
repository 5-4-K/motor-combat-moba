export function applyDamage(hp: number, amount: number): number {

### Task 2: Ram damage (TDD)

`ram.ts`:

```ts
export function isRamming(
  ax: number, ay: number, angle: number,
  bx: number, by: number,
  threshold: number,
): boolean

export function ramOutcome(
  aRams: boolean,
  bRams: boolean,
): "both" | "a_hits_b" | "b_hits_a" | "none"

export function ramDamage(strength: number, per: number): number
```

`isRamming`: `dot(forward, normalize(b-a)) >= threshold`. If distance 0, return false.

Tests:

1. A at (0,0) facing 0 (toward +x), B at (10,0) → A rams, B facing 0 does **not** ram A (B faces away from A). `ramOutcome` → `a_hits_b`.
2. B facing `π` → both ram → `both`.
3. A facing `π/2` (toward +y), B at (10,0) → glancing → `none`.
4. `ramDamage(8, 1) === 8`.

### Task 3: Projectiles (TDD)

`projectiles.ts`:

```ts
export interface Proj {
  id: string;
  ownerSessionId: string;
  x: number; y: number; angle: number; speed: number;
  spawnTick: number; alive: boolean;
}

export function stepProjectile(p: Proj, dt: number): Proj

export function projectileHitsObstacle(p: Proj, obstacles: Aabb[], bounds: {width:number;height:number}): boolean

export function projectileHitsCar(p: Proj, car: Obb): boolean

export function canDamage(
  ownerId: string,
  ownerTeam: 0 | 1,
  targetId: string,
  targetTeam: 0 | 1,
  mode: "ffa" | "team",
): boolean
```

Rules:

- `stepProjectile`: `x += cos(angle)*speed*dt`, same for y. (`speed` here is u/s, use `WEAPON_CONFIG.projectileSpeed`.)
- Hits obstacle or leaves bounds → not alive (caller sets).
- Hits car: point-in-OBB or small circle vs OBB. Use a point test at `p.x,p.y` against the car OBB.
- `canDamage`: false if `ownerId === targetId`. FFA: true for any other. Team: true iff `ownerTeam !== targetTeam`.

Tests: travel distance over 1s ≈ 900; hit wall; ignore self; ignore teammate in team mode; damage enemy in team mode; lifetime: caller kills when `tick - spawnTick >= lifetimeTicks`.

- [x] **Step 1: Tests + impl.** Commit `feat: projectile motion and hit rules`

### Task 4: Server tick — fire, move, ram, win

**Fire:** if phase is `MATCH` and `input.fire` and `player.weaponCooldown === 0` and `player.alive` and `player.carId !== ""`:

- Spawn `ProjectileState` with new id (`${sessionId}-${seq}` or incrementing counter), pose at car nose (`x + cos(angle)*nose`, `y + sin(angle)*nose`, `nose = carWidth/2`).
- `weaponCooldown = ceil(TICK_RATE_HZ / WEAPON_CONFIG.fireRateHz)`.

Each tick, decrement `weaponCooldown` on living players (min 0).

**Move projectiles** with `stepProjectile`. Then for each alive projectile:

1. If `tick - spawnTick >= lifetimeTicks` → delete.
2. If `projectileHitsObstacle` → delete.
3. For each **other** living roster player, if `canDamage` and `projectileHitsCar` → `hp = applyDamage(hp, WEAPON_CONFIG.damage)`; delete projectile; if `hp === 0` → `alive = false`. **One target only** (first in sorted sessionId order).

**Ram:** after movement `resolveWorld`, for each pair of living roster cars (sessionId a < b) whose OBBs overlap **and** `tick >= cooldown[pair]`:

- Compute `ramOutcome`.
- Apply `applyDamage` per outcome using each attacker’s `CAR_TABLE[carId].strength * collisionDamagePerStrength`.
- Set `cooldown[pair] = tick + collisionDamageCooldownTicks`.
- If hp 0 → `alive = false`.

Do **not** apply ram damage on the same tick as spawn-protection (there is none).

**Win:** after damage, `livingSides`. If `sides <= 1` and phase is MATCH, `endMatch(...)`. **Delete `stub_end_match`.**

**Disconnect:** already treated as not alive in P3; keep that.

**Spectate data:** `alive === false` is enough. Client handles camera.
